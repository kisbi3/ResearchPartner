## Review Packet Checklist

Each reviewable result should include:

- what changed since the previous iteration
- affected physical system, model, equation, simulation, figure, or claim
- assumptions and parameter regime
- baseline and validation status
- figures, tables, logs, or derivations shown
- claims currently supported
- claims not yet supported
- specific questions for the researcher
