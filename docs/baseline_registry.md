## Rules

Every new model, solver, analysis pipeline, or figure workflow should identify at least one baseline before full-scale interpretation.

Acceptable baseline types include:

- toy model with known behavior
- analytically solvable limit
- reproduction of a published result
- reproduction of a previous validated output
- conservation-law sanity case
- dimensional sanity case
- simplified parameter regime

If the baseline gate is waived, record the reason and remaining risk.
