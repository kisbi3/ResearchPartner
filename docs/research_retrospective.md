## Rules

Every completed research iteration should leave behind at least one reusable artifact:

- benchmark script
- toy model
- reproduction recipe
- validation command
- dimensional check
- anomaly record
- hypothesis result
- decision log entry
- claim-to-evidence map
- tacit pattern

If an iteration leaves no reusable artifact, record why.
