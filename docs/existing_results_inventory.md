## Rules

Existing results should not be treated as validated merely because they already appear in notes, slides, figures, or manuscript text.

For each result, identify:

- what generated it
- which data and parameters were used
- which physical claim it supports
- whether it has a baseline, dimensional check, convergence check, uncertainty estimate, or reproduction record
- whether it should remain active, be revised, or be deprecated
