## Rules

Record anomalies that affect scientific interpretation or reproducibility.

For each anomaly, record:

- smallest reproduction
- affected assumptions, parameters, or scripts
- diagnostics already run
- whether it is physical, numerical, implementation-related, data-related, plotting-related, or unresolved
- next diagnostic
