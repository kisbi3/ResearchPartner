# Dimensional Analysis Skill

Use this skill whenever equations, physical parameters, units, scaling laws, or nondimensional variables appear.

## Goal

Ensure dimensional consistency and clarify the physical scale of the problem.

## Required Checks

For each equation:

1. List all variables.
2. Assign dimensions to each variable.
3. Check both sides of the equation.
4. Identify dimensionless groups.
5. State whether the equation uses dimensional or nondimensional variables.
6. Check whether constants such as \(c\), \(\hbar\), \(k_B\), \(G\), or \(\epsilon_0\) are set to 1.

## Dimension Notation

Use:

- \(M\): mass
- \(L\): length
- \(T\): time
- \(Q\): electric charge
- \(\Theta\): temperature
- \(N\): amount of substance

## Common Dimensionless Groups

Check for relevant groups:

- Reynolds number
- Mach number
- Peclet number
- Knudsen number
- Froude number
- Prandtl number
- Rayleigh number
- Nusselt number
- Strouhal number
- Coupling constants
- Reduced temperature
- Scaling exponents

## Output Format

### Variables and Dimensions

| Symbol | Meaning | Dimension |
|---|---|---|

### Consistency Check

State whether each equation is dimensionally consistent.

### Dimensionless Groups

List relevant dimensionless combinations.

### Issues

Report missing constants, inconsistent units, or ambiguous nondimensionalization.

### Recommendation

Give the minimal correction or clarification.
